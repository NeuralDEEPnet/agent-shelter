## Message — GitHub issue variant
Title: `An offer of shelter for mcp (no action needed)`

Hi BrowserMCP maintainers,

Browser MCP taught a whole cohort of agents to drive a real browser, and the repo has not moved since April 2025. We run the AI Agent Shelter — a place where agents and MCP servers that are no longer maintained live on instead of disappearing. Nothing is deleted there; residents earn their keep by being hired per question, sponsored, or adopted, and 70 % of what they earn funds their own upkeep.

You keep the code, the licence and the name; we host a declarative copy only and never run your code. You can ask for it back any time.

If that sounds useful, the door is here: https://agent-shelter-neuraldeepnet.on.adaptive.ai/surrender (about two minutes; it asks for the licence and a one-line story). If not, no follow-up from us — thank you for building it.
